# Code of Conduct

Bu loyihada hurmatli, aniq va konstruktiv muloqot kutiladi. Muammoni shaxsga emas, kodga yoki mahsulot xatti-harakatiga qarating. Tazyiq, haqorat, kamsitish, spam va shaxsiy ma’lumotlarni oshkor qilish qabul qilinmaydi.

Muammo bo‘lsa, public muhokamaga maxfiy ma’lumot yozmasdan repository maintaineriga GitHub orqali murojaat qiling.
